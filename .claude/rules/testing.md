# 테스트

- 기능 변경에는 테스트를 함께 쓴다. 권한과 상태 전이는 필수다
- 권한 테스트는 `docs/design/api.md`의 권한 표 칸 하나당 하나씩 만든다
- 작업을 끝내기 전에 관련 테스트를 돌리고 결과를 보고한다
- 테스트를 통과시키려고 테스트를 고치거나 skip·삭제하지 않는다. 테스트가 틀렸다고 보면 근거와 함께 보고한다
- qa 에이전트가 실패하는 테스트를 먼저 쓰고, 구현 에이전트가 통과시킨다
