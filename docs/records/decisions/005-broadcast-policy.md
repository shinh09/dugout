# 005. 방송 상태·녹화·채팅 정책

- 방송 1건 = 라이브 1회, READY → LIVE → ENDED 단방향. LIVE 전환은 LiveKit 웹훅(첫 영상 트랙) 기준
- 동시 LIVE 1개, READY 최대 5개, 최대 3시간, 송출 끊김 60초 후 자동 종료
- 라이브 중 수정은 제목·설명만, 삭제는 READY·ENDED만(VOD·채팅 함께)
- 모든 방송 자동 녹화(720p), 방송당 VOD 1개
- 채팅 작성은 LIVE에서만, 수정·삭제는 작성자만, 1초 1개·같은 내용 3회 차단
- 이유: 상태 관리가 단순해야 '방송 상태 관리' 평가와 테스트가 명확해짐
