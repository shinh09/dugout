# 권한 테스트 생성

1. `docs/design/api.md`의 권한 표에서 대상 API의 행을 찾는다
2. 칸마다 테스트 하나: 비로그인(401) / 다른 사용자(403 또는 허용) / 소유자·작성자(허용) / 상태 조건(409)
3. 테스트 이름은 `{동작}_{사용자}_{기대결과}` (예: `update_otherUser_returns403`)
4. 테스트 계정은 픽스처로: 스트리머(소유자), 시청자(다른 사용자)
5. 실행 후 결과를 `docs/test/auth-matrix.md` 표에 반영한다(통과 ✔ / 실패 ✘)
