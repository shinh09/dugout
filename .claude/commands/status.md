GitHub 상태를 `gh`로 확인해서 아래 형식으로 짧게 요약해 줘.

1. 단계별 진행률: `stage:필수`, `stage:선택`, `stage:제출` 라벨별로 닫힌 이슈 / 전체 이슈와 %
2. 마감(2026-11-19 23:59 KST)까지 남은 일수와, 지금 속도로 필수 단계를 끝낼 수 있는지 한 줄 판단
3. 열린 PR: 제목, CI 상태, 답하지 않은 리뷰 댓글 수
4. 막힌 이슈: 담당 라벨과 막힌 이유
5. 오늘 추천 작업 3개 (필수 단계 우선)

판단 기준: 11/14까지 필수 100%가 아니면 선택 단계 범위를 줄이자고 제안해.
