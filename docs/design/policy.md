# 서비스 정책

> 원본: Cowork 서비스 정책서(2026-11-08). 각 규칙은 그대로 서버 검증과 테스트 케이스가 돼요. 권한 상세는 [api.md 권한 표](api.md#auth-matrix).

## 1. 회원

| 항목 | 규칙 | 위반 시 |
| --- | --- | --- |
| 이메일 | 이메일 형식, 중복 불가 | 400 / 409 EMAIL_DUPLICATED |
| 비밀번호 | 8~20자, 영문+숫자 포함 | 400 |
| 닉네임 | 2~12자, 한글·영문·숫자, 중복 불가 | 400 / 409 NICKNAME_DUPLICATED |
| 내 팀 | 선택, 카테고리 11개 중 1개 또는 없음 | — |
| 로그인 유지 | access 30분, refresh 14일, 로그아웃 시 즉시 무효 | 401 → 재발급 시도 |
| 로그인 실패 | "이메일 또는 비밀번호가 올바르지 않아요"로 통일 | 401 |
| 로그인 시도 제한 | 같은 IP 1분 10회 | 429 |

테스트 계정: 로그인 화면에 **테스트 스트리머 / 테스트 시청자** 버튼 2개. 서버 시작 시 자동 생성(is_test=true), 스트리머 계정에는 시연용 종료 방송·다시보기 포함. 회원 탈퇴·프로필 수정은 범위 밖.

## 2. 방송

| 항목 | 규칙 | 위반 시 |
| --- | --- | --- |
| 제목 | 1~100자, 공백만 불가 | 400 |
| 설명 | 0~1000자 | 400 |
| 카테고리 | 11개 중 1개 필수 | 400 |
| 송출 방식 | PC / MOBILE 필수 | 400 |
| 동시 라이브 | 사용자당 LIVE 1개 | 409 ALREADY_LIVE |
| 예정 방송 수 | 사용자당 READY 최대 5개 | 409 TOO_MANY_READY |
| 최대 방송 시간 | 3시간 초과 시 자동 종료 | 자동 ENDED + 안내 |
| 송출 끊김 | 60초 안에 재연결 없으면 자동 종료 | 자동 ENDED |

- 라이브 탭에는 LIVE만, 기본 정렬 시청자순. READY는 공개 목록에 노출하지 않음
- 시청 중 종료되면 "방송이 종료되었어요 · 다시보기 준비 중" 표시
- 삭제는 READY·ENDED만, 복구 불가, 채팅·다시보기 함께 삭제, 확인 창 필수
- 상태별 수정 가능 항목은 [api.md 상태 전이](api.md#state)

## 3. 다시보기

| 항목 | 규칙 |
| --- | --- |
| 녹화 | LIVE 전환 시 자동 시작, 종료 시 자동 중지, 선택 옵션 없음 |
| 화질 | 720p 기본 |
| 공개 범위 | 전체 공개 |
| 제목·설명 | 방송 정보를 그대로 사용 |
| 목록 노출 | 처리 완료(READY)만, 처리 중이면 시청 화면에 '준비 중' |
| 녹화 실패 | 목록 제외, 내 방송 관리에 '녹화 실패' 표시 |
| 보관 기간 | 공모전 기간 무기한 |
| 재생 | S3 비공개, 1시간짜리 서명된 URL |

다시보기 화면에서는 라이브 때 채팅을 읽기 전용으로 보여줘요.

## 4. 채팅

| 항목 | 규칙 | 위반 시 |
| --- | --- | --- |
| 작성 가능 방송 | LIVE만 (READY·ENDED는 읽기 전용) | 409 |
| 글자 수 | 1~200자, 공백만 불가 | 400 |
| 연속 작성 | 1초에 1개 | 429 |
| 같은 내용 반복 | 연속 3번째부터 차단 | 429 |
| 수정 | 작성자만, '(수정됨)' 표시 | 403 |
| 삭제 | 작성자만, '삭제된 메시지예요' 표시 | 403 |
| 삭제된 메시지 | 다시 수정·삭제 불가 | 409 |

- 닉네임 옆 내 팀 배지(팀컬러 점), 방송 소유자 메시지에 '스트리머' 표시
- 입장 시 최근 50개, 위로 스크롤하면 이전 메시지
- 비로그인 사용자가 입력창을 누르면 로그인 → 보던 방송으로 복귀

## 5. 콘텐츠 운영

- TV·OTT 경기 화면 재송출 금지. 방송 등록·송출 시작 전 안내 문구
- 구단 로고·엠블럼·마스코트 미사용, 팀명 텍스트와 팀컬러만
- 모든 화면 하단: "덕아웃은 KBO 및 각 구단과 무관한 팬 서비스입니다"
- 권장 형식: 그래픽 입중계(PC), 기록·데이터 분석(PC), 직관·현장(모바일), 얼굴 토크
- 외부 기록 사이트 화면 공유 시 해당 사이트 이용약관 준수
- 신고·제재, 금칙어는 범위 밖
