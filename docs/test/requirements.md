# 요구사항 충족 근거 (코드밋 제출용)

구현 후 `/docs-update`가 코드 위치를 채워요.

## 필수

| 요구사항 | 구현 내용 | 코드 위치 | 상태 |
| --- | --- | --- | --- |
| PC 방송: 화면 공유 + 탭/시스템 소리 + 마이크 송출, 다른 기기에서 시청 | | | 미구현 |
| 모바일 방송: 카메라 + 마이크 송출, 다른 기기에서 시청 | | | 미구현 |
| 방송 등록·수정·삭제, 목록·상세, 방송 중/종료 구분, 종료 시 송출 중단 | | | 미구현 |
| 방송 정보 영구 저장(서버 재시작 후 조회) | | | 미구현 |
| 회원가입·로그인·로그아웃, 인증 상태 관리 | | | 미구현 |
| 로그인 사용자만 등록·송출, 서버에서 소유자 권한 확인 | | | 미구현 |
| 비로그인·소유자·다른 사용자 접근 허용/거절, 목록·시청은 비로그인 허용 | | | 미구현 |

## 선택

| 요구사항 | 구현 내용 | 코드 위치 | 상태 |
| --- | --- | --- | --- |
| 댓글: 작성·목록·수정·삭제, 서버 작성자 권한 확인 | | | 미구현 |
| 녹화·다시보기: 저장, 목록·상세·재생, 재시작 후 조회 | | | 미구현 |
| 도네이션 | 범위 제외(확장 구조만) | | 제외 |
