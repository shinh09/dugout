# 001. 야구 팬 방송 컨셉과 서비스명 '덕아웃'

- 결정: KBO 팬 스트리머 방송 플랫폼. 카테고리 11개(KBO 10개 구단 + 국가대표 1개), 방송 유형은 라이브/다시보기
- 이유: 팀 응원 스트리머(예: 불방망이)가 인기를 얻는 흐름. SOOP에서 스트리머 입중계 수요는 검증됐지만 팀 단위로 탐색하는 전용 플랫폼은 없음
- 비시즌(11월) 대응: 다시보기가 목록을 채우고, 국대 대회 기간엔 홈 배너로 노출
- 버린 대안: 스토브리그 토크 유형(범위 축소), 팀/국대 전용 페이지(카테고리 칩과 중복), 스트리머 수동 입력 스코어보드(사용성 낮음)
- 제약: 경기 중계 영상 재송출 금지, 구단 로고 미사용
